<h2><br><img src="https://cdn.serilum.com/description/nameplate/about-the-mod.svg" alt="About the mod" width="838" height="64"></h2>
<p><span style="font-size:18px">Wandering Trader May Leave adds a simple way to ask the wandering trader to exit the map without resorting to violence. It adds a small button in the top left of the trade screen. When clicked, the trader disappears in a cloud of particles. You no longer have to kill it to get some peace and quiet.<br><br>The Trader Llamas disappear as well, but only if they are leashed to the trader. This behaviour can be changed in the config.</span></p>
